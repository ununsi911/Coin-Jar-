# Coin Jar

A kid-friendly piggy bank. Add and spend money and watch the jar fill toward a saving goal.

- Profiles: each person gets their own jar, with a color and an optional 4-number PIN.
- Backup code: copy a code from the profile panel and paste it on another phone to move a jar.
- Everything is saved on the device. There are no accounts and no server.

Open the site, then add it to your home screen:
- iPhone: Safari, tap Share, then Add to Home Screen.
- Android: Chrome, tap the menu, then Install app.
